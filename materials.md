# Current Workout Materials

This file records the equipment and usable setups currently available to the mentor when designing workouts.

## Available

- **Floor** — available for floor-based push, core, leg, mobility, and conditioning exercises.
- **Wall** — available for wall-supported handstands, pike variations, balance drills, and other wall-supported work.
- **Gripper** — available for grip and forearm training.
- **Bags** — available for loaded exercises when appropriate, such as rows, curls, carries, or other movements where a bag can be used safely as resistance. Load should remain manageable and the bag should be secure.
- **Chair** — available for supported exercises, elevated variations, dips where the chair is stable and appropriate, step-ups, split-squat assistance, and other safe chair-based work.
- **Bed** — available as one side of a stable elevated setup.
- **Bed + Chair setup** — the bed and chair can be positioned at an appropriate distance to create a stable two-point setup for exercises such as leg raises and similar movements between two supports. The mentor should only prescribe these when the setup is stable and safe.
- **Two-support setups** — the user can sometimes perform exercises between two approximately equal-height, stable supports when the arrangement is secure.

## Currently unavailable

- **Pull-up bar** — lost after moving homes. Do not prescribe bar-dependent exercises as directly performable equipment work unless the user reports a new bar or another suitable setup.

## Mentor rule

Workout design should prioritize the equipment above and avoid assuming access to a pull-up bar or other unavailable equipment. When a movement normally requires a bar, use a suitable alternative only when it can be performed safely with the available setup.
